# StudyFit — AI 학습 습관 분석기

공부 시간, 수면 시간, 스마트폰 사용 시간, 휴식 시간을 입력하면
머신러닝 모델이 **집중도 점수를 예측**하고, 습관을 개선할 수 있는 **맞춤형 조언**을 보여주는 Streamlit 웹앱입니다.

> ⚠️ **교육용 프로젝트입니다.** 대학교 머신러닝프로젝트(RISE) 수업의 최종 과제로 만들었습니다.
> 학습에 사용한 데이터는 실제 학생 데이터가 아니라 **공식으로 만든 가상 데이터**이므로,
> 예측 결과는 참고용 시연일 뿐이며 **실제 집중도를 보장하지 않습니다.**

## 주요 기능

- **홈 / 학습 습관 입력 / 분석 결과** 3개 화면 (사이드바에서 전환)
- 입력값 검증: 숫자가 아니거나 음수이거나 하루 합계가 24시간을 넘으면 **오류**, 학습 데이터 범위를 벗어나거나 수면이 4시간 미만·스마트폰이 8시간 이상이면 **경고**
- 집중도 점수 예측 (0~100점) 과 등급 표시: 70점 이상 높음 / 40점 이상 70점 미만 보통 / 40점 미만 낮음
- 입력한 습관의 막대그래프와 맞춤형 학습 조언
- 입력값과 결과는 화면을 이동해도 유지됩니다.

## 입력값과 출력값

| 구분 | 내용 |
|---|---|
| 입력 | 하루 평균 공부 시간, 수면 시간, 스마트폰 사용 시간, 휴식 시간 (0.1시간 단위, 네 항목 합계 24시간 이하) |
| 출력 | 집중도 예측 점수(0~100, 소수 첫째 자리), 등급(높음/보통/낮음), 맞춤형 조언 |

학습할 때만 정답으로 `focus_score`(집중도 점수)를 사용하며, **예측할 때는 집중도 점수를 입력받지 않습니다.**

## 머신러닝 예측과 규칙 기반 조언의 차이

| | 집중도 점수 예측 | 맞춤형 조언 |
|---|---|---|
| 방식 | **머신러닝** (scikit-learn `LinearRegression`) | **규칙 기반** (`if`문으로 미리 써 둔 문구 선택) |
| 파일 | `model.py` | `advice.py` |
| 동작 | 데이터에서 학습한 계수로 점수 계산 | 예: 수면 6시간 미만이면 수면 조언, 스마트폰 5시간 이상이면 스마트폰 조언 |

조언은 머신러닝이 만든 것이 아니며, 의료적 진단이나 실제 집중도에 대한 확정적인 판단이 아닙니다.

## 데이터와 모델 성능

- 가상 학습 데이터 **500개** (`data/study_data.csv`)를 `data_generator.py`로 생성했습니다. 난수 시드를 고정해 항상 같은 데이터가 나옵니다.
- 집중도 점수는 아래의 임의 공식에 무작위 오차(표준편차 5점)를 더해 만들었습니다.

  `집중도 = 40 + 3.0×수면 − 2.5×스마트폰 + 1.5×공부 + 2.0×휴식 + 오차` (0~100점으로 제한)

- 데이터를 학습용 80%(400개) / 평가용 20%(100개)로 나누어 학습하고 평가했습니다.

| 지표 | 값 | 뜻 |
|---|---|---|
| MAE | **3.78점** | 가상 평가 데이터에서 예측이 정답과 평균 약 3.78점 차이 났습니다. |
| R² | **0.841** | 가상 평가 데이터 점수 변화의 약 84%를 모델이 설명했습니다. |

**이 수치는 가상 평가 데이터에서 얻은 결과이며, 실제 학생에 대한 정확도가 아닙니다.**
데이터를 직선 공식으로 만들었기 때문에 선형 모델이 잘 맞는 것은 당연한 결과입니다.
모델은 현실을 학습한 것이 아니라 공식을 다시 찾아낸 것입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 웹앱 (화면 3개) |
| `model.py` | 모델 학습, 저장/불러오기, 집중도 예측 |
| `validators.py` | 입력 검증 (오류/경고) |
| `advice.py` | 규칙 기반 맞춤형 조언 |
| `data_generator.py` | 가상 데이터 생성 |
| `data/study_data.csv` | 가상 학습 데이터 (500행) |
| `models/focus_model.joblib` | 학습된 모델 |
| `tests/` | 자동화 테스트 (pytest) |
| `PLAN.md` | 초기 개발 계획서 (현재 구현과 다를 수 있음) |

## 설치 및 실행

Python 3.11 환경에서 개발하고 확인했습니다.

```bash
cd StudyFit
pip install -r requirements.txt
streamlit run app.py        # 브라우저에서 http://localhost:8501
```

저장소에 학습된 모델(`models/focus_model.joblib`)이 포함되어 있어 바로 실행할 수 있습니다.
모델을 다시 만들고 싶다면 아래 순서로 실행하세요.

```bash
python data_generator.py    # 가상 데이터 생성 (data/study_data.csv)
python model.py             # 모델 학습, 평가, 저장 (MAE/R² 출력)
```

> 모델 파일은 scikit-learn **1.9.1**로 만들었습니다. `requirements.txt`에 버전을 고정해 두었으니 그대로 설치하세요.
> 다른 버전에서 모델을 불러올 수 없다면 `python model.py`로 다시 학습하면 됩니다.

## 테스트

```bash
python -m pytest -q
```

입력 검증, 모델 학습·저장·예측, 조언 문구에 대한 테스트 47개가 있습니다.
(테스트용 모델은 임시 폴더에 만들어 쓰므로 `models/focus_model.joblib`을 덮어쓰지 않습니다.)

## 한계

- 실제 학생 데이터가 아닌 가상 데이터로 학습했습니다.
- `LinearRegression`은 직선 관계만 표현합니다. "공부는 적당할 때가 가장 좋다" 같은 곡선 관계는 반영하지 못합니다.
- 학습 데이터 범위(공부 0~12, 수면 3~10, 스마트폰 0~10, 휴식 0~5시간) 밖의 입력은 예측이 부정확할 수 있어 경고를 표시합니다.
- 조언은 일반적인 생활 습관 상식에 기반한 참고용 문구입니다.
